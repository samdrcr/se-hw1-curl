Raw cURL: Understanding HTTP from the Ground Up

A hands-on implementation opening the black box of HTTP using native sockets.

View Source Code on GitHub →

📌 Core Concept

HTTP is not magic—it is simply plain-text strings transferred across a reliable TCP stream (with TLS handling encryption for HTTPS).

🐍 Python (v1)

Socket + SSL

Implements synchronous, blocking I/O to read and parse chunked HTTP response streams manually.

⚡ TypeScript (v2)

net + tls Modules

Demonstrates event-driven, non-blocking Buffer handling across network streams.

🚀 Quick Start

# Run Python implementation
python3 python_curl.py https://jsonplaceholder.typicode.com/posts/1

# Run TypeScript implementation
npx tsx ts_curl.ts https://jsonplaceholder.typicode.com/posts/1
