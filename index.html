📌 Core Concept & Philosophy

High-level libraries like requests or fetch abstract network communications into a single method call. This project opens that black box to prove that HTTP is fundamentally an unencrypted, human-readable plain-text protocol riding on top of a reliable TCP stream (secured via a TLS handshake for HTTPS).

🐍 Python (v1: Synchronous)

Standard socket + ssl

Demonstrates blocking socket streams, explicit byte conversions, manual HTTP header generation, and stateful chunked payload decoding.

⚡ TypeScript (v2: Asynchronous)

Node.js net + tls

Demonstrates non-blocking, event-driven networking using binary Buffers without invoking higher-level HTTP client interfaces.

🔍 Raw HTTP Packet Walkthrough

When running a request, this exact string is encoded into bytes and written to the socket:

GET /posts/1 HTTP/1.1\r\n
Host: jsonplaceholder.typicode.com\r\n
User-Agent: MyRawCurl/1.0\r\n
Accept: application/json, */*\r\n
Connection: close\r\n
\r\n

The empty trailing line (\r\n\r\n) serves as the delimiter separating headers from the request payload.
